## 项目入口

| 文件 | 用途 |

## 维护约定

- 新增面向本项目的说明时，优先写入根 `README.md` 或新增明确命名的 `docs/*.md`。
- 如果保留参考与当前代码冲突，以当前代码和项目级文档为准。
- 修改本地 API、状态持久化、运行命令或目录职责时，同步更新根 `README.md`。
