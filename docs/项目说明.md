但你这里的计时器不是普通番茄钟，也不是死板 break timer。你的要求“规则是死的，人是活的”非常关键，所以计时系统应该叫：

```text id="n4m9e9"
Flexible Focus Timer
弹性专注计时器
```

它应该有三类规则：

```text id="05s1nx"
硬规则：
  例如睡觉前不再开长 session；休息不能无限跳过；每日上限不能超过 16h。

软规则：
  例如建议 50min + 10min，但允许延长、提前结束、拆分。

人工覆盖：
  人可以随时调整、跳过、合并、拆分、补记，但系统记录原因。
```

分割方式要比你现在灵活。你现在更像按分类投入和补记时间，新版应该支持这些模式：

```text id="o6wup4"
1. 正向计时
   直接开始，结束后归档到任务。

2. 预算分割
   例如“今天数学 3 小时”，系统自动拆成 60+50+40+30。

3. 弹性番茄
   默认 50+10，但 50 分钟后不是强制停，而是提示“继续/休息/切任务”。

4. 截止倒推
   例如 22:30 前完成论文阅读，系统根据剩余时间自动分割。

5. 活动校准
   如果 ActivityWatch 显示你离开电脑 12 分钟，系统自动把 session 切成 focus + afk + focus。

6. 人工修正
   你可以手动把 80 分钟 session 拆成 50 分钟数学 + 30 分钟论文。
```

这就是“规则是死的，人是活的”：规则给建议，最终以人的实际工作为准；但每次偏离都被记录，复盘时能看到“计划如何被现实修正”。
