# 上游能力整合

本文是当前仓库事实，记录曾放在根目录的开源项目副本被移除后，仍保留能力的正式归属。工作区运行、构建和测试不依赖这些上游源码目录。

## 能力归属

| 来源 | 保留能力 | 当前实现位置 | 集成方式 |
|:---|:---|:---|:---|
| 旧时间管理原型 | 任务队列、弹性计时、每日复盘、Token/GitHub 热力图 | `apps/homepage/src/components/workstation/dashboard.jsx`、`services/workbench-core` | 使用工作站 contracts 与 SQLite 重写；不再加载旧 SPA 或 `localStorage` 状态 |
| ActivityWatch | 当前窗口、AFK、今日应用统计 | `services/workbench-core/src/adapters/activitywatch.ts`、`apps/desktop-shell/src/services/activityWatchProcess.ts` | core 只读 `aw-server` REST API；Windows 安装包携带官方二进制运行时并由桌面壳托管 server/window/AFK watcher 生命周期，不重写 watcher |
| Tokei | Claude/Codex 等本地 AI 工具 token、缓存命中和成本统计 | `services/workbench-core/src/adapters/activityStats.ts` | Windows 安装包携带 collector、价格表和 Python 标准运行时；只读本地会话日志，不自动联网更新价格 |
| BreakTimer | 周期休息、软提醒、强提醒、允许人工继续 | `services/workbench-core/src/modules/breakReminder.ts` | 以纯规则模块实现，计时器不中断；Homepage 展示提醒 |
| Super Productivity | Project、Task、Tag、上下文、timeboxing 语义 | `packages/contracts/src/index.ts`、`services/workbench-core/src/modules/repository.ts` | 采用工作站自己的精简领域模型与数据库，不接入其 Angular UI 或数据库 |

旧 Task Manager 的静态构建目录 `apps/homepage/public/embedded/task-manager` 也已删除；`/workstation` 当前页面已经覆盖对应入口。
