# 开发计划

## 已完成的阶段二 MVP 骨架

- pnpm monorepo。
- `apps/homepage` 迁移并新增 `/workstation` 页面。
- `services/workbench-core` 提供 Fastify API、SQLite 表和 Drizzle schema。
- `packages/contracts` 与 `packages/theme`。
- 任务、计时、ActivityWatch、Tokei/GitHub、音乐 mock、每日复盘闭环。

## 阶段二剩余打磨

- 完善 Homepage widget 化拆分，把当前 `/workstation` 页面里的面板拆成可复用组件。
- 为 `activity_snapshots` 增加真实缓存写入。
- 增加 `timer_policies` 的 CRUD。
- 为 ActivityWatch summary 增加真实 timeline 查询和 AFK segment 校准。
- 对 Tokei/GitHub payload 做更精确的 token 与贡献总量适配。

## 阶段三：可自定义工作站

详见 [设置页面.md](./设置页面.md)。

当前已完成：

- `workstation_settings` 与 `widget_settings` 表。
- `WorkstationSettings`、`WidgetSettings` 等 contracts 类型。
- `workbench-core` settings API。
- `/settings/workstation` 页面。
- 模式、Widgets、任务/项目、计时器、音乐、ActivityWatch、活动统计、主题、隐私、封装入口的基础 UI。
- settings 会影响 ActivityWatch 地址、Tokei 路径、GitHub 用户名、音乐启用状态和 `/workstation` widget 显示。

目标：

- `/settings/workstation` 页面。
- 工作站模式配置。
- widgets 配置。
- 任务/项目配置。
- 计时策略配置。
- 音乐、ActivityWatch、Tokei/GitHub 配置。
- 主题、导入导出和隐私设置。

剩余优先级：

1. Widget 布局拖拽与 reorder UI。
2. 完整旧 Task-Manager 导入预览和确认写入。
3. 数据删除二次确认 UI。
4. timer policy 表单细化。
5. settings 与环境变量优先级说明。

## 阶段四：封装与发布

详见 [封装与发布.md](./封装与发布.md)。

目标：

- Docker / self-hosted 部署。
- Windows desktop shell。
- 数据目录、自动启动、托盘、快捷键、全屏 break。
- 发布前 smoke test 与数据持久化验证。

当前已完成：

- `deploy/docker-compose.yml`。
- monorepo-aware Homepage Dockerfile 和 `workbench-core` Dockerfile。
- `apps/desktop-shell` Electron 壳，包含主窗口、托盘、快捷键和 core 子进程骨架。
- Windows 用户数据目录默认映射到 Electron `userData/data/workbench.sqlite`。

剩余优先级：

1. Docker build/push CI。
2. 桌面壳内置生产 Homepage 静态资源。
3. 安装包图标、签名、自动更新和 smoke test。
